Sistema de Gerenciamento de Publicidades
📌 Sobre o projeto

Sistema desenvolvido como teste técnico para o Grupo Embras, com o objetivo de gerenciar publicidades vinculadas a múltiplos estados.

Tecnologias utilizadas
- Angular + PrimeNG (Frontend)
- Ruby on Rails (Backend) 
- PostgreSQL (Banco de dados)
- Docker + Docker Compose

🚀 Como rodar o projeto
1 - Clone o repositório:
  git clone URL_DO_REPOSITORIO

2 - Acesse a pasta:
cd "Projeto Embras"

3 - Execute:
docker compose up --build

🌐 Acessos

Frontend:
http://localhost:4200

Backend:
http://localhost:3000

📋 Funcionalidades
Cadastro de publicidades
Edição de publicidades
Listagem com imagem
Encerramento de publicidade
Upload de imagem
Associação com múltiplos estados

🐳 Docker
O projeto está totalmente containerizado, permitindo execução com um único comando:
docker compose up --build
